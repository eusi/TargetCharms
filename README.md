# TargetCharms

Mark targets, place world markers, and start ready checks without digging through menus. TargetCharms brings your group's coordination tools together in compact, movable toolbars you can arrange to fit your UI.

<img width="227" height="190" alt="TargetCharms toolbars" src="https://github.com/user-attachments/assets/822a27ca-4699-4666-a756-6f8c2684dec1" />

**Clients:** Retail, WoW Forever, Classic Era, Mists Classic, TBC Classic

## Features & controls

- **Settings:** `/tc` or Ctrl + right-click a toolbar. Aliases: `/tc setup`, `/targetcharms`.
- **Target icons:** Left-click to mark your target; clear button to remove. Optional click-again toggle.
- **World markers:** Click a color, then the ground. Clear button removes all markers.
- **Ready Check:** Left-click to start; requires group permissions.
- **Move:** Enable **Show move handle**, then left-drag the four-arrow handle. Disable to lock.

Configure outside combat. World markers require client support and group permissions.

## Settings

- **Show / hide:** Sidebar switches for each toolbar — also apply while settings are open.
- **Grid:** Choose columns; rows adjust automatically.
- **Presets:** Horizontal, vertical, 3 columns, original, alternate.
- **Reorder:** Click two preview icons to swap them.
- **Appearance:** Size, opacity, icon spacing; Ready Check text and width.
- **Visibility:** Group-only; target icons optionally require a target.
- **Advanced:** Optional layout-code editor, up to 20 slots. Syntax help is in settings.
- **Saving:** Automatic. Hover over controls for help.

## Profiles & reset

- **Main profile:** Share this character's settings with your other characters.
- **Copy:** Import the main profile's settings and positions after confirmation.
- **Reset all settings:** Restore defaults after confirmation. Available here instead of `/tc reset`.

## Installation

- **[CurseForge](https://www.curseforge.com/wow/addons/targetcharms):** Install via the app.
- **Manual:** Extract `TargetCharms` into `Interface/AddOns/`.
