# TargetCharms

TargetCharms gives you a floating toolbar for quick access to charms and raid target icons. Arrange the buttons in any order and customize their spacing, opacity, position, and size. A movable **Ready Check** button and a **world marker / flare** toolbar make it useful for party and raid leaders.

**Clients:** Retail, WoW Forever, Classic Era, Mists Classic, and TBC Classic.

## Installation

1. **[CurseForge](https://www.curseforge.com/wow/addons/targetcharms):** Install via the app.
2. **Manual:** Download the release ZIP and extract the `TargetCharms` folder into your WoW client's `Interface/AddOns/` directory. Enable **TargetCharms** in the game's AddOns list.

## Controls

- **Target icons:** Left-click an icon to mark your current target. Use the clear button to remove the icon.
- **Toggle icons:** Enable this option in settings to remove a marker by clicking the same icon again.
- **Ready Check:** Left-click to start a ready check when your group permissions allow it.
- **World markers:** Left-click a marker, then choose its location in the world. Use the clear button to remove world markers.
- **Move icons or Ready Check:** Right-click and drag with **Draggable** enabled in settings.
- **Move world markers:** Use the small drag handle on the toolbar.
- **Open settings:** Ctrl+right-click a toolbar or enter `/tc setup`.

Move and configure toolbars outside combat. World markers are available where supported by the client.

## Commands

- `/tc setup` - Open settings.
- `/tc reset` - Restore defaults.
- `/tc` - Show command help.

You can also use `/targetcharms` instead of `/tc`.

## Custom layouts

Choose a preset in settings or enter a custom layout. Each button uses a direction followed by an icon: `>1>2>3` places star, circle, and diamond in a horizontal row.

- **Directions:** `>` right, `<` left, `^` up, `v` down.
- **Target icons:** `1` star, `2` circle, `3` diamond, `4` triangle, `5` moon, `6` square, `7` cross, `8` skull, `0` clear.
- **World markers:** `B` blue, `G` green, `P` purple, `R` red, `Y` yellow, `O` orange, `S` silver, `W` white, `D` drag handle, `X` clear all.
- **Spacer:** `_` leaves an empty slot.

Layouts support up to 20 slots.
